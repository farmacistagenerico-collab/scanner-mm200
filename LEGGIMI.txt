AGGIORNAMENTO DEL SITO SU GITHUB — 2 passaggi
=============================================

Questo pacchetto riporta il repository all'ultima versione: tre mercati
(Italia, Germania, Francia), sei sezioni del sito, e il workflow che le
aggiorna da solo.

PASSAGGIO 1 — codice e pagine (tutti i file TRANNE aggiorna.yml)
  1. apri:  https://github.com/farmacistagenerico-collab/scanner-mm200/upload/main
  2. trascina nella pagina TUTTI i file di questa cartella tranne "aggiorna.yml"
     (i 27 file .py, requirements.txt e le 8 pagine .html)
  3. in fondo: "Commit changes" -> "Commit changes"
  >> Appena salvato, il sito mostra subito le sei sezioni collegate.

PASSAGGIO 2 — il workflow che tiene tutto aggiornato
  1. apri:  https://github.com/farmacistagenerico-collab/scanner-mm200/upload/main/.github/workflows
     (questo indirizzo carica gia' dentro la cartella giusta: nessuna rinomina)
  2. trascina: aggiorna.yml
  3. in fondo: "Commit changes" -> "Commit changes"

PROVA
  https://github.com/farmacistagenerico-collab/scanner-mm200/actions
  -> "Aggiorna dashboard" -> "Run workflow" -> attesa ~12 minuti
     (il primo giro ricalcola anche i backtest dei tre mercati)

IL SITO (sei sezioni, barra di navigazione su ogni pagina)
  https://farmacistagenerico-collab.github.io/scanner-mm200/
